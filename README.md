📢 Bulk WhatsApp Messaging
📌 Project Purpose

Bulk WhatsApp Messaging is a backend platform that enables businesses to send bulk messages to customers through the WhatsApp Business API. It is designed to simplify customer engagement, marketing campaigns, and automated notifications at scale.

✨ Features

Send bulk WhatsApp messages via the WhatsApp Business API.

Manage and organize customer contact lists.

Message scheduling and delivery tracking.

API endpoints for easy integration with other systems.

Scalable and secure backend design.

🛠️ Tech Stack

Language: Python

Frameworks: Django REST Framework

Database: PostgreSQL

Messaging: WhatsApp Business API

Deployment: Docker / Heroku / AWS

🚀 Installation
# Clone repository
git clone https://github.com/Nyakudziguma/Bulk-Whatsapp-Messaging.git
cd Bulk-Whatsapp-Messaging

# Create virtual environment
python -m venv venv
source venv/bin/activate   # On Windows use venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

▶️ Usage
# Run the server
python manage.py runserver

📖 Example Use Cases

Marketing teams running promotional campaigns.

Businesses sending bulk updates (e.g., order status, reminders).

Customer engagement through personalized messaging.

🔒 Notes

This project requires access to the WhatsApp Business API.

Ensure you have valid credentials and API keys before use.
